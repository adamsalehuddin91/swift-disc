# 🎮 DISC for Kids - Kenal Karakter Kanak-Kanak

**8-Bit Personality Assessment Web App for Children** (Ages 5-12)

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Visit: **http://localhost:3000**

**Duration**: 5-7 minutes

---

## ✨ Features

- 🎮 **15 Interactive Questions** - Fun scenario-based DISC assessment
- 👑 **4 Personality Types** - Leader, Cheerful, Caring, Careful
- 🎨 **8-Bit Retro Theme** - Pixel art, retro fonts, scanlines
- 📊 **Visual Results** - Animated score breakdown
- 💡 **Parenting Tips** - Practical guidance for each type
- 🖨️ **Print/Share** - Save or share results
- 📱 **Mobile-First** - Responsive design
- 🇲🇾 **Bahasa Malaysia** - Full BM support

## 🛠️ Tech Stack

- **Next.js 15** + React 19
- **TypeScript 5**
- **Tailwind CSS 4**
- **Press Start 2P** (Google Fonts)
- **Client-side only** (no database needed)
